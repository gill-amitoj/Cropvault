# Sample data

`station_drop/` holds **synthetic** images (drawn shapes, not real plants) plus sidecar JSON
files, generated by `make_samples.py`. They exercise every ingestion path:

| Files | Expected result |
|---|---|
| `wheat_*`, `canola_*` with a `.json` sidecar (JPEG, PNG, TIFF, one EXIF-rotated) | `processed/`, metadata from sidecar |
| `ST02_Wheat_20260512_001.jpg` etc. (no sidecar) | `processed/`, metadata from filename |
| `wheat_plot01_day01_resend.jpg` (same bytes as `wheat_plot01_day01.jpg`) | `processed/`, API 409 = duplicate |
| `random_photo.jpg` (no sidecar, no pattern) | `failed/` |
| `ST04_Oat_20261399_001.jpg` (impossible date) | `failed/` |
| `corrupt_scan.jpg` (text, not an image) | `failed/`, API 400 |
| `unknown_experiment.jpg` (sidecar names `EXP-9999`) | `failed/`, API 400 |
| `operator_notes.txt` | `failed/`, unsupported file type |

Run the demo: `cp sample_data/station_drop/* data/station_drop/`

Regenerate: `docker compose run --rm -v ./sample_data:/sample_data api python /sample_data/make_samples.py`
